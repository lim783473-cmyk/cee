# cee — 少一点复制粘贴

**cee** 是一个 Chrome 扩展：复制一段文字（或一张截图）后，点中网页表单里的输入框，按 `Alt+V`，cee 会识别字段并自动填入。`Ctrl+V` / `Cmd+V` 永远保持原生粘贴，不拦截、不改写。

- 在线演示（免安装，19 个真实感场景）：**<https://cee.songm.dpdns.org/>**
- 安装后零配置即可试用：默认连接作者的公共试用网关，试用阶段**不需要 token**。

---

## 安装（约 1 分钟）

1. 点页面右上角 **Code → Download ZIP** 下载本仓库，解压到任意目录；
2. 打开 Chrome，地址栏输入 `chrome://extensions` 回车；
3. 打开右上角 **开发者模式**；
4. 点左上角 **加载已解压的扩展程序**，选择解压出来的文件夹（里面有 `manifest.json` 的那一层）；
5. 固定工具栏上的 cee 图标，方便随时唤出。

> 更新版本：重新下载 ZIP 覆盖文件夹，回到 `chrome://extensions` 点 cee 卡片上的刷新按钮即可。

## 使用

1. 复制一段文字（客户信息、简历、工单描述……）；
2. 点中网页表单里的一个输入框；
3. 按 `Alt+V`（macOS 是 `Option+V`）——cee 识别字段并填入，拿不准的字段留空不猜；
4. 填错了点工具条上的 **撤销**；`Esc` 取消进行中的操作。

**工具条默认隐藏**：普通浏览、复制文字、聚焦字段都不会弹出底部工具条；只有按 `Alt+V` 或点扩展按钮（快捷键 `Ctrl+J`）时才显示，点关闭后也不会被后台事件再次弹出来。

**截图输入**：剪贴板里没有文字、只有图片时，`Alt+V` 会先 OCR 识别，弹出可编辑的预览，确认后再填入。

## 它会做什么 / 不会做什么

| 会 | 不会 |
| --- | --- |
| 填入的值必须来自你复制的原文的精确位置 | 不会让模型“生成”或改写内容 |
| 没把握的字段留空（置信门槛 0.85 / 0.9） | 不会猜测下拉框选项 |
| 支持 Shadow DOM、React 受控表单、iframe、原生 `<select>` 与 ARIA combobox | 不会自动提交表单 |
| 页面拒绝写入时恢复原值并提示原因 | 不会覆盖你已填写的字段 |
| 密码、验证码、支付/证件号等敏感字段直接排除 | 不会读取、保存或上传你的剪贴板历史 |

## 隐私

- 填表时，只有你按了 `Alt+V` 的那一次剪贴板文字、字段标签和表单标题会发送到**你配置的网关**，用于匹配；不会发送字段值、DOM id 或整个页面。
- 默认网关是作者的公共试用网关（`https://cee.songm.dpdns.org`），试用阶段无需 token。
- 一切处理完成后不留存：扩展不保存剪贴板历史，网关侧也不落盘。

## 自托管 / 私有化

cee 采用**瘦客户端**架构：这个仓库里的扩展只负责表单识别与写入，匹配算法运行在网关侧（不在本仓库中）。

- 想用自己的网关：打开 cee 设置（工具条齿轮或扩展详情页），把 **cee gateway URL** 换成你自己的地址即可；如果网关启用了 token，在设置里填同一个值。
- 网关程序暂未公开发布，如需私有化部署请联系作者。

## 常见问题

- **按 `Alt+V` 没反应？** 先点中一个文本输入框；密码框、验证码等敏感字段会被跳过，这是故意的。
- **没匹配上？** cee 会把剪贴板原文原样粘贴进当前字段，不会丢内容。
- **能自动提交吗？** 不能，也不会有。cee 只填表，提交永远由你来做。
